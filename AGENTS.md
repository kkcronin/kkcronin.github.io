# AGENTS.md — Rules for working on this site

This is Caitlin (KK) Cronin's personal/professional website, published via GitHub Pages
(kkcronin.github.io). It is public to the entire internet. These rules apply to any
agent (Claude or otherwise) working in this repo.

## Never publish without explicit permission

- **Personal phone number.** Never put a phone number on any public page.
- **Personal/school email addresses** (e.g. Columbia email). Default contact method is
  the LinkedIn and GitHub links only, unless KK explicitly asks for an email to be shown.
- **Home address or any physical location more specific than a city.**
- **Unreleased or confidential employer information** — anything from Adobe or Deloitte
  work that isn't already phrased the way it appears on the public resume (no internal
  project names, client names beyond what the resume already discloses, proprietary
  data, or screenshots of internal tools).
- **Other people's personal info** (recommenders, colleagues, classmates) without their
  consent — no full names + contact details of third parties.
- Any content from a resume/CV revision that hasn't been explicitly shared for this
  website (if KK updates her resume file, ask before pulling new details in, in case
  something was left off intentionally).

## Always ask first before

- **Pushing to GitHub / deploying** (`git push`, enabling GitHub Pages, merging to
  `main`). Local commits and local preview are fine to do without asking; publishing
  live is not.
- Adding or changing contact methods (email, phone, calendly links, contact forms).
- Adding analytics/tracking scripts or third-party embeds.
- Making significant structural changes (new pages, nav changes, removing sections)
  versus small content/style tweaks.
- Any changes based on a new/updated resume file dropped into the repo — confirm which
  sections changed and that it's OK to reflect them publicly.

## Style

- **Tone:** professional but casual/approachable — this is a personal site, not a
  corporate one. Warm, direct, a little personality is welcome (e.g. in interests),
  but keep the experience/education sections crisp and resume-accurate.
- **Visual identity:** Columbia blue (#B9D9EB-ish) as the primary accent, paired with a
  dark navy/blue for contrast and text. Clean, modern, generous whitespace.
- **Navigation:** keep it minimal — a single streamlined nav bar, no deep menus. Prefer
  one-page scroll with anchor links over multiple separate pages unless KK asks for
  more pages.
- **Content accuracy:** all resume content (titles, dates, metrics, bullet points)
  should match the source CV exactly — don't embellish, round, or editorialize numbers.
- **No stock photography of strangers, no placeholder "lorem ipsum" left in shipped
  pages, no fake testimonials.**
- Keep the codebase simple: static HTML/CSS/(minimal JS), no build step/framework
  unless KK asks for one.
